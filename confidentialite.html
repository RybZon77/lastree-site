Politique de confidentialité

Mise à jour le 21 octobre 2026 · version 0.34 du jeu et suivantes

  • Rien ne part du téléphone sans votre accord.
  • Même avec votre accord : jamais le prénom, la date de naissance, le code secret ni le personnage.
  • Pas de publicité, pas de compte, aucune adresse e-mail demandée.

La case « aider à améliorer L'astrée »

Dans le jeu, elle s'appelle « Aider à améliorer L'astrée ». Elle apparaît sous la date de naissance, et dans le menu. Elle est décochée au départ, et vaut pour tout le téléphone, quel que soit l'âge du joueur. Pour un enfant, c'est le parent qui décide de la cocher.

Tant qu'elle est décochée, le jeu n'envoie rien du tout.

Ce qui ne part jamais, même case cochée

  • le prénom
  • la date de naissance
  • le code secret
  • le personnage et sa photo
  • aucune capture d'écran
  • aucun identifiant publicitaire

Tout cela reste sur le téléphone, avec le Carnet, les badges et les réglages. Le code secret n'y est même pas gardé tel quel : le jeu n'en garde qu'une empreinte. Désinstaller le jeu efface tout.

Le jeu ne montre aucune publicité et ne demande ni compte ni adresse e-mail. Il n'envoie pas non plus de rapport quand il plante.

Ce qui part, seulement si la case est cochée

Des statistiques, pour voir où les joueurs s'arrêtent et ce qu'ils choisissent, et améliorer le jeu. Je les lis sur un tableau de bord.

Chaque envoi porte aussi la tranche d'âge du profil : enfant, ado ou adulte.

Qui les reçoit : Unity Technologies, l'entreprise qui fabrique l'outil avec lequel le jeu est construit (son service Unity Analytics). Le jeu y est déclaré comme destiné aux enfants. Unity garde ces statistiques surtout dans l'Union européenne (Belgique, Pays-Bas), avec une copie aux États-Unis. La politique de confidentialité d'Unity.

Unity reçoit aussi, de lui-même, l'adresse IP du téléphone (le numéro de sa connexion à internet), qui lui donne le pays, et un numéro tiré au hasard à l'installation. Ce numéro compte des téléphones, pas des personnes : il ne dit pas qui joue.

Sur quelle base : votre accord, donné en cochant la case.

Combien de temps

Unity garde le détail des statistiques 13 mois, puis l'efface de lui-même. Les chiffres du tableau de bord sont gardés jusqu'à ce qu'on demande leur effacement : vous, en décochant la case, ou moi. Ce qu'en dit Unity.

Vos choix

  • Décocher la case, dans le menu du jeu : les envois s'arrêtent aussitôt, et le jeu demande à Unity d'effacer ce que ce téléphone a envoyé, sous 30 jours.
  • Désinstaller le jeu efface ce qu'il gardait sur le téléphone. Pour effacer aussi les statistiques, décochez d'abord la case.
  • Une question, une demande : écrivez-moi. Vous pouvez aussi vous adresser à la CNIL, sur cnil.fr.

Ce site

Ce site ne demande aucune adresse e-mail, ne dépose aucun cookie et ne compte pas ses visiteurs. Il est hébergé par GitHub Pages ; GitHub peut noter l'adresse IP des visiteurs (le numéro de leur connexion à internet), pour sa sécurité.
